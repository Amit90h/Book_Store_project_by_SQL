# Online Book store analysis by SQL
#  Book Store SQL Analysis

##  Overview

This project showcases SQL-based analysis of an online Book Store database using PostgreSQL. It includes database design and business-oriented SQL queries to extract valuable insights from books, customers, and orders.

##  Database

The project consists of three tables:

* **Books** – Book details, genre, price, and stock
* **Customers** – Customer information and location
* **Orders** – Purchase records and sales data

##  Tools

* PostgreSQL
* SQL
* pgAdmin

##  SQL Concepts Used

* Filtering (`WHERE`)
* Sorting (`ORDER BY`)
* Aggregate Functions (`SUM`, `AVG`, `COUNT`)
* `GROUP BY` & `HAVING`
* `INNER JOIN` & `LEFT JOIN`
* `COALESCE`
* Data Analysis Queries

##  Business Questions Solved

* Retrieve books by genre and publication year
* Find customers by country
* Calculate total stock and total revenue
* Identify the most expensive and lowest-stock books
* Analyze genre-wise book sales
* Find average book prices by genre
* Identify frequent customers and best-selling books
* Calculate author-wise sales
* Find top-spending customers
* Analyze remaining inventory after fulfilling orders
